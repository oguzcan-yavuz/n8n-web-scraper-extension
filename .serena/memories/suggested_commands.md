# Suggested Commands

## Chrome Extension Development
- Reloading: Open `chrome://extensions/` and click the reload icon on the "n8n Web Scraper" card.
- Debugging: 
  - Background Script: Click "service worker" link in `chrome://extensions/`.
  - Content Script: Right-click page -> Inspect -> Console (ensure correct frame is selected).
  - Options Page: Right-click extension icon -> Options -> Right-click page -> Inspect.

## System Utils (Darwin)
- `ls -lah` (Standard Darwin `ls`)
- `grep -r "pattern" .` (Standard Darwin `grep`)
