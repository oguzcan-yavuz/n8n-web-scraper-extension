# Tech Stack

## Extension
- Manifest V3
- Chrome Extension API
- Service Workers (background script)
- Content Scripts
- Storage API (`chrome.storage.sync`)

## Frontend
- Vanilla JavaScript
- Markdown (via `marked.min.js`)
- CSS-in-JS (via `Object.assign(overlay.style, ...)` and `<style>` injection)

## Backend
- n8n
- Gemini (Google AI)
